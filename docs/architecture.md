## 模組設計原則

### Frontend
- **元件分離**：Scene3D 與 Panels 獨立
- **計算邏輯抽離**：lib/* 純函式可被測試
- **型別嚴格**：TypeScript strict mode
- **資料外部化**：法規資料放 data/*.json

### Calc Engine
- **Pydantic 模型**：所有結構元素用 BaseModel 確保型別
- **純函式**：計算函式不修改輸入
- **可測試**：單元測試覆蓋核心計算
- **可組合**：takeoff()、cost()、report() 各自獨立

### pyRevit
- **單一 Transaction**：失敗自動 rollback
- **參數化**：避免 hardcode 路徑、檔名
- **使用者確認**：破壞性操作前確認
- **錯誤處理**：必要時跳過該構件而非中止整個流程
