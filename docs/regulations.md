## 2. 建築技術規則 §70（防火時效）

**自頂層起算（含地下層數）**：

| 主要構造部分 | 不超過4層 | 5~14層 | 15層以上 |
|------------|----------|--------|---------|
| 承重牆壁     | 1 hr     | 1 hr   | 2 hr    |
| 樑          | 1 hr     | 2 hr   | **3 hr** |
| 柱          | 1 hr     | 2 hr   | **3 hr** |
| 樓地板       | 1 hr     | 2 hr   | 2 hr    |
| 屋頂        | 0.5 hr   | 0.5 hr | 0.5 hr  |

**注意**：
- 屋頂突出物未達計算層樓面積者，防火時效應與頂層同
- 「層數」包括地下層數
- 「自頂層起算」意指從建築物最上層開始計算位置

**範例**：22F 地上 + 3F 地下 = 25 總層
- 22F~19F (頂層~第4層) → 柱/梁 1 hr
- 18F~9F (第5~14層) → 柱/梁 2 hr
- 8F~B3F (第15層以上) → 柱/梁 3 hr

## 3. 建築技術規則 §46-6（樓板隔音）

**施行日期**：民國 110 年 1 月 1 日

**適用建築物**：
- 集合住宅
- 住宅、宿舍、旅館、長照機構等供居住用之場所

**性能要求**：
- 衝擊音降低量 ΔLw ≥ 17 dB（路徑 A）
- 衝擊音降低量 ΔLw ≥ 20 dB（路徑 B）
- 樓板衝擊音規格化噪音位準 Ln,w ≤ 58 dB

### 路徑 A（一般做法）

```
施工順序（自下而上）：
┌─────────────────────────────┐
│ RC 樓板 ≥ 150mm                │  ← 結構板
├─────────────────────────────┤
│ 橡膠緩衝材 ≥ 8mm                │  ← 隔音層
│ (動態剛性 ≤ 50 MN/m³)          │
├─────────────────────────────┤
│ 鋼筋/鋼絲網                    │
├─────────────────────────────┤
│ 混凝土地板 ≥ 50mm（總厚 60mm）   │  ← 表面層
└─────────────────────────────┘

總組合厚度: 150 + 8 + 60 = 218mm
代表 ΔLw ≥ 17 dB
```

### 路徑 B（薄板選項）

- RC 樓板 ≥ 120mm
- 高性能緩衝材，ΔLw ≥ 20 dB
- 或取得內政部高性能綠建材標章

### 工具預設

工具中對住宅/商業用途量體預設採用路徑 A：
- 結構板：150mm
- 隔音層：68mm（含緩衝材 8mm + 表面 60mm）
- 總厚：218mm

## 4. 建築物耐風設計規範

**回歸期**：50 年（基本設計風速）
**離地高度**：10 公尺
**地況**：平坦開闊地面
**風速平均時間**：10 分鐘

### 基本設計風速分區

| 風速 (m/s) | 適用區域 |
|-----------|---------|
| 47.5      | 花蓮市、吉安鄉、恆春鎮、滿州鄉 |
| 42.5      | 臺北市、基隆市、新北市部分（汐止/淡水/瑞芳等）、宜蘭沿海、花蓮部分鄉鎮 |
| 37.5      | 一般地區（中西部主要城市） |
| 32.5      | 內陸盆地 |

### 設計風力計算

**主要風力抵抗系統**：
```
F = q × Cf × G × A
```
其中：
- q：風速壓 (kN/m²)
- Cf：風力係數（1.3 一般矩形建物）
- G：陣風反應因子（≈ 2.0）
- A：迎風面積 (m²)

**風速壓**：
```
q = 0.06 V² (kgf/m²)
```
V 為設計風速（m/s）

### 用途係數

- 一般建築：I = 1.0（50 年回歸期）
- 公共建築：I = 1.1（增加重要性）
- 重要建築：I = 1.2（醫院、消防、緊急應變）
